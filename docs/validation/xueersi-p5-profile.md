# 学而思 P5 屏幕规格的本地 Android 验证

验证日期：2026-11-10。此记录是原生 Android 模拟器中运行实际 APK 的结果，不是 P5 真机或学而思固件的认证。

## 环境与依据

- 学而思官方 P5 宣传资料给出 12.6 英寸、2.4K 屏幕：https://weibo.com/2/detail/5354230925492366
- 公开规格给出 2400×1600：https://www.ithome.com/1/021/087.htm
- 未找到可信的 P5 Android 底层版本、固件版本和出厂逻辑密度；经用户授权，使用本地 Android 15 / API 35 基线。
- 独立 AVD：`luoye-p5-profile-api35`；ARM64、6GB 配置、2400×1600，覆盖 240dpi 与 320dpi；设备身份仍是通用 Pixel Tablet，没有伪装成 P5。
- 实际 WebView：124.0.6367.219。模拟器不能还原真实 12.6 英寸玻璃、触控笔、护眼屏、处理器和学而思权限管理。
- 正式签名包执行安装、冷启动、作品打开和返回键复核。功能细查使用同一 store 配置的 debug APK，通过 ADB 和 WebView CDP 操作按钮及真实触摸事件；截图均来自 `adb screencap`。

## 功能结果

- 11 种画笔逐一触摸落笔；撤销/重做、橡皮、儿童调色板、图形、中文文字、辅助对称、主题切换通过。
- 无品牌写实背景、组合连续盖章、8 帧动态魔法袋、独立动画素材、图层、画夹保存、像素画和小动画编辑器通过。
- 滤镜混合场景、动画帧保留、撤销/重做及取消回滚共 38 项检查通过。模拟器单次滤镜处理约 2.27 秒，不能据此推断 P5 真机性能。
- 系统 Storage Access Framework 实际保存工程、导出 PNG/JPEG；文件已落盘并拉回主机核对格式。重新打开后核对图层 ID 和动画帧结构一致。
- 草稿通过“画夹 → 自动保留 → 打开”恢复：后台、强制停止并重启后，标题及图层数一致。当前设计不是启动时自动恢复弹窗。
- 飞行模式下加载另一张本地背景通过。
- 音乐播放器原生状态为 playing，位置从约 0.57 秒前进到 3.18 秒；模拟器关闭音频输出，没有验证真实听感。
- 240dpi 和 320dpi 下触摸绘画、画板铺满通过；界面大小及全屏切换通过；软键盘打开后确认按钮仍可见。
- 上线配置为 1582 条素材、无旧版条目、无项目/捐献入口。
- 222 项 Node 测试、Android lint 和 debug/release 构建通过。

## 发现并修复

1. Android 15 对 targetSdk 35 强制 edge-to-edge，原先 WebView 覆盖 `[0,0]–[2400,1600]`，系统栏遮挡顶部控件。增加原生容器，统一处理系统栏、挖孔和 IME Insets。普通窗口初次复测内容区域为 `[0,54]–[2400,1552]`；全屏和键盘变化时动态调整。
2. Android 15 新版返回分发没有进入旧 onBackPressed。API 33+ 注册 OnBackInvokedDispatcher，旧版本保留原入口；返回先取消最上层弹窗，重复返回也可取消保存/退出提示，保留未保存作品保护。

Android 官方 Insets 说明：https://developer.android.com/develop/ui/views/layout/edge-to-edge

## 实测边界与已知行为

- 系统文件面板会为 application/json 工程追加 `.json`，实际名称例如 `P5-native-final.luoyex.json`；本次验证可以重新打开。
- 学而思家长管控、安装白名单、OEM 文件面板限制、真实手写笔压感、防误触、音频听感和 P5 真机性能仍需目标设备验证。
- 自动化初次执行的个别等待/选择器问题均保留原始日志，并用对应补测结果交叉核对；不能把原始失败日志当成最终结论。
