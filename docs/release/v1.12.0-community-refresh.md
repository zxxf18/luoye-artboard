## 安装注意

- **macOS**：当前只做本机 ad-hoc 签名，未做 Developer ID 签名或公证，安装与校验方式见[项目说明](https://github.com/zxxf18/luoye-artboard#macos-安装提示)。
- **Windows**：安装器需要 .NET 10 Desktop Runtime；解压后请保留同目录文件。
- **iPad**：IPA 未签名，不能直接当作已签名商店包安装；需要使用自己的 Apple 签名配置。iPad 采用全屏横屏，不支持 Split View / Stage Manager。
- **Android**：附件使用新的正式签名。旧测试签名版本通常无法覆盖安装，需先导出工程备份，再卸载旧版后安装；卸载会清除应用内本地数据。Android 版本号仍为 1.12.0。
- 所有安装包与静态资源包的 SHA-256 均列在 [SHA256SUMS.txt](https://github.com/zxxf18/luoye-artboard/releases/download/v1.12.0/SHA256SUMS.txt) 中。
