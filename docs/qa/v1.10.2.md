# v1.10.2 界面巡检与修复

2026-09-18。先将本地 `main` 与 `origin/main` 同步至 `903c22ab`，再在隔离的浏览器配置和 macOS 临时 WKWebView 数据存储中执行巡检。

## 修复结果

- 900 × 650 小窗口开启特大按钮时，顶部音乐、界面大小按钮可同时完整显示，保留至少 44 px 点击区域。
- 镜像图层的矩形擦除、选区、动态印章缩放和整块擦除按可见位置计算；合并及暗房效果烘焙像素后清除已经应用的镜像标记，避免二次翻转。
- 动态魔法袋的暗房选区和局部滤镜使用镜像后的世界坐标，命中用户点选的位置。
- 录像支持镜像属性、当前 200 层容量，保存组合魔法袋的当前位置和切换工具时的重置；没有新增字段的旧录像仍按原默认值读取。
- 仿制笔触在起笔时冻结源像素，避免源画布的绘制指令在圆形裁切时重新栅格化，从而与 PNG 恢复的录像源产生边缘差异。Chrome 与 WKWebView 都验证了逐像素一致的回放。
- 图层透明 PNG 导出通过统一的图层渲染路径，包含当前动画帧和擦除蒙版。继续按图层原始尺寸输出透明素材。
- 更新素材目录迁移后的旧测试路径、子分类选择和异步操作等待。分形实验入口延续远程版本的隐藏设置。

## 复现命令

先启动 `npm run dev`，以下界面脚本默认访问 `http://127.0.0.1:4187`，可通过 `LUOYE_TEST_URL` 指定。Playwright 通过 `LUOYE_PLAYWRIGHT` 指向现有安装，浏览器为本机 Chrome。通用回归脚本自行启动服务，可通过 `LUOYE_BROWSER_EXECUTABLE` 指定浏览器。

```sh
npm test
node tools/browser-acceptance.mjs
node tools/verify-interface.mjs
node tools/verify-tool-actions.mjs
node tools/verify-tool-feedback.mjs
npm run build:mac
LUOYE_SMOKE_FILES=1 LUOYE_SMOKE_RELOAD=1 node tools/native-acceptance.mjs \
  native-operations native-tool-feedback native-new-session native-display \
  native-selection-v170 native-interaction-repair native-darkroom-matrix \
  native-interface-audit native-mirror-recording native-close-v163 native-close-discard-v163
npm run build:windows
npm run build:windows:installer
```

本地明细保存在 `build/interface-acceptance/`、`build/browser-acceptance.json`、`build/acceptance/v1.10.2/` 和 `design/versions/v1.10.2/evidence/`。生成的包位于 `build/releases/v1.10.2/`。所有旧版交付包和用户作品均保留。
