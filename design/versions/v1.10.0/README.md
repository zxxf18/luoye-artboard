# v1.10.0 · 音效音量与光标落点

音乐盒新增独立的工具音效音量，默认 60%，振荡器增益由 0.045 提升至 0.09。滑动时更新百分比和设置，松开后试听当前工具；0% 不发声，关闭音效时也不试听。背景音乐音量与工具音效音量分别保存，旧版关闭音效的选择继续保留。

54 种工具状态使用图案本身作为光标，取消左上方的独立小点。40 px 光标按图案坐标配置实际操作位置：铅笔和蜡笔尖端、刷子毛端、喷笔喷嘴、橡皮接触边、魔法棒星形顶端、取色器尖端等。八种油漆桶光标重新绘制为倾斜小桶和流出少量颜料，操作位置对齐颜料末端。几何与圈选光标分别对齐图中的笔尖和箭头尖端；移动、缩放、图案等工具使用工作中心。

验收与构建：

- 构建前 53 项 Node 测试通过，覆盖音量默认值、升级兼容、零音量、非法存储、静音取消与光标坐标。
- 浏览器逐项点击全部 54 种状态，实际 CSS 使用各自的光标落点；54 张 SVG 解码后的图像和 54 段声音各不相同。
- OfflineAudioContext 实测 0%、30%、60%、100% 的音频输出；零音量无输出，新默认音量峰值约为旧增益设置的两倍。
- 音量滑块支持键盘，调节后试听，静音开关和 0% 均有效；不影响背景音乐音量。
- 独立 Chrome 完整关闭再打开，恢复工具音量 99%、音乐 17、背景音乐音量 2%、停止状态及关闭音效的选择。浏览器音乐测试使用测试专用原生桥模拟，真实 MIDI 由 macOS 验收覆盖。
- 真实鼠标点击在适合窗口、放大画布及 900×650 窗口下，都改变了笔尖所指的预期画布像素。放大的光标落点图已逐项查看；辅助线仅用于验收。
- macOS WKWebView 15 项客户端验收通过：真实音效峰值约 0.0842，音量保存为 37% 后重载恢复；图示光标、倾倒油漆桶落点、静音、原生 MIDI 和音乐设置恢复均正常。
- macOS、Windows win-x64 自包含客户端和 Windows 安装器构建通过；两平台内嵌脚本与最终源码一致。Windows 尚未实机验收。

复验命令：`npm test`；开发服务运行后执行 `node tools/verify-tool-feedback.mjs`、`node tools/verify-cursor-contact.mjs`（可用 `LUOYE_PLAYWRIGHT` 指向 Playwright）；Mac 构建后执行 `LUOYE_SMOKE_RELOAD=1 node tools/native-acceptance.mjs native-tool-feedback`。

正式产物保留在 `build/releases/v1.10.0/`。文本验收证据在 `evidence/`，截图与音效试听文件仅在本地保留。清理范围仅含本轮测试目录、临时安装器打包目录和中间构建目录。
